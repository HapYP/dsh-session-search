# 会话内容搜索

补上内置侧栏搜索框不具备的两个搜索入口：

1. **跨工作区内容搜索面板** — 按 `Ctrl+Shift+F`，或点击侧栏底部的放大镜按钮。
   输入关键字即可对**所有工作区中的全部会话**做全文搜索，覆盖用户消息、助手回复、
   工具调用（名称 + 参数）、工具结果与任务清单条目。点击结果即可打开对应会话。
   `Enter` 打开选中项，`↑`/`↓` 移动选择，`Esc` 关闭；命中较多时可点“加载更多”翻页。
2. **会话内查找栏** — 在会话中按 `Ctrl+F`（焦点不在文本编辑器内时生效）。会在会话
   上方浮出查找栏，高亮当前已渲染的聊天内容中的全部匹配项，带命中计数、上一个/下一个
   导航并平滑滚动定位。`Enter` / `Shift+Enter` 逐个跳转，`Esc` 关闭。

## 工作原理

- 浏览器半部负责渲染搜索面板、查找栏与侧栏按钮，并通过同源鉴权的 `/api` 路由
  调用 Host 半部。
- Host 半部把查询转发给 DSH 自带的 `ctx.sessionQuery` 全文搜索服务（内置
  **会话搜索** 插件挂载的 SQLite FTS5 后端），返回带排序与纯文本摘录的结果；
  不直接读写会话存储。

## 要求与限制

- 全文搜索依赖内置 **会话搜索** 插件处于启用状态；若未启用，面板会明确提示
  缺少后端，而不是静默失败。
- 匹配规则是**字面、大小写不敏感、空白灵活的子串扫描**：词中片段也会命中
  （`AI` 能命中 `BRAID`），词之间任意空白（含换行）都能匹配。不是按词元或短语匹配。
- 思考过程（reasoning）文本未被 DSH 索引，因此不可搜索。
- `Ctrl+F` 查找栏只覆盖会话当前已渲染的内容；尚未渲染的更早回合请改用
  跨工作区搜索面板。
- 搜索面板先扫描最近的一批会话（约 40 个），数秒内给出结果；需要更早的会话时
  点击“继续扫描更早的会话”向后翻页。非活跃会话在被读取过一次后会缓存在 Host
  内存中（不落盘、上限 128 MB），重复搜索已扫描过的会话接近即时。
